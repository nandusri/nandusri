## About Me

I'm a **Data Engineering Technical Lead** passionate about designing scalable data platforms, building reliable data pipelines, and solving complex engineering problems.

My work revolves around transforming raw data into meaningful, trusted, and production-ready data assets.

- Building scalable ETL / ELT pipelines.
- Designing modern Lakehouse architectures.
- Working with distributed data processing.
- Optimizing large-scale data workloads.
- Exploring cloud-native data engineering.
- Sharing practical engineering knowledge.
